# Chart pie Fix
Some info
In Minecraft exists debug tool - Pie Chart accessiable via F3 + 1. It is a graph where you can analyze game processing data, it acts as a radar for unrendered blocks and entities, letting you easily locate hidden structures, mob spawners and secret bases.
## Setup
Just put mod in /mods folders , mod requiers Fabric loader and Fabric Api
## How to use
For access sub categories you need to select them via numbers 0-9 on keyboard, but category can have id more then 9 and this mod adds function press Shift + 0-9 to access this category.
For example for category 10 u need to press Shift + 0, for element 15 shift + 5.
